# Nova AI

ChatGPT jaisi chatbot website. Is mein shamil hai:
- Apna login / sign up (email aur password), har user ki chats alag aur private
- Chat history (search aur delete ke saath)
- Nova 1 Fast, Nova 1, Nova 1 Pro (teen speed/quality levels)
- Image banana ("sunset ka image banao" ya Create image button) aur PNG download
- Light, Dark aur Auto theme, phone par bhi theek chalti hai
- Upar right corner mein "Generated by Maher"

Yeh Claude ke andar nahi, aap ke apne computer ya hosting par alag website ki tarah chalti hai.

## 1. Pehli baar setup (sirf 10 minute)

**a) Node.js install karein** (ek baar): https://nodejs.org par jayein, "LTS" wala button dabayein, install karein.

**b) Free key banayein (payment nahi chahiye):** https://aistudio.google.com/apikey par Google account se log in karein, "Create API key" dabayein aur key copy kar lein. Nova ke jawab Google ki Gemini free service se chalte hain.
Free service ki limits hoti hain (kuch messages per minute aur per din). Agar bohat log use karein to "busy" ka message aa sakta hai. Google free tier mein chats ko apni service behtar banane ke liye istemal kar sakta hai, is liye users ko private ya hassas baatein likhne se mana karein.
Behtar jawab ke liye baad mein Claude ki paid key bhi laga sakte hain (`.env.example` mein Option B).

**c) Chalayein:**
- Windows: `start.bat` par double click karein. Pehli baar Gemini key paste karne ko kahega.
- Mac / Linux: Terminal mein `./start.sh`

Phir browser mein kholein: **http://localhost:3000**
"Sign up" dabayein, account banayein aur chat shuru karein.

Band karne ke liye black window mein Ctrl + C dabayein.

## 2. Kharch aur limit

Free service ki apni limits hain, aur paid key lagayen to har message paisa kharch karta hai. Is liye har user ke liye roz ki limit hai (default 60 messages, aur image 4 messages ke barabar). `.env` file mein `DAILY_LIMIT` badal sakte hain.
Agar sirf apne logon ko allow karna hai to `.env` mein `SIGNUP_CODE=koi-code` likhein. Phir sirf wohi account bana sakenge jinhein aap yeh code dein.

## 3. Doosron ke liye online karna

Aap ke computer par chalne se sirf aap (ya aap ke wifi ke log) use kar sakte hain. Poori duniya ke liye is folder ko kisi hosting par chalana hota hai, jaise Render, Railway ya koi VPS.

Hosting par yeh settings dein:
- Start command: `node server.js`
- Environment variables: `GEMINI_API_KEY` (ya `ANTHROPIC_API_KEY`), `TRUST_PROXY=1`, `SIGNUP_CODE` (agar chahein), `DATA_DIR` (neeche dekhein)
- Hosting `PORT` khud deti hai, usay badalna nahi.

Zaroori: users aur chats `data/db.json` file mein save hoti hain. Is liye hosting par "persistent disk / volume" lagayein aur `DATA_DIR` us disk ke path par set karein. Bina disk ke (jaise Render ka free plan) har restart par accounts aur chats mit jaayenge.
HTTPS hosting khud deti hai. Bina HTTPS ke login cookie safe nahi hoti.

## 4. Kuch aham baatein

- `.env` file aur `data/` folder kisi ko share na karein aur GitHub par na daalein. In mein aap ki key aur users ka data hai.
- Images vector drawings (logo, poster, illustration, scene) hain. Photo jaisi asli tasveer ke liye alag image-service chahiye hoti hai.
- Password bhoolne ka option abhi nahi hai. Agar koi user bhool jaye to `data/db.json` mein se uska account hata kar naya bana sakte hain.
- Models ke naam `.env` mein `MODEL_FAST`, `MODEL_NOVA`, `MODEL_PRO` se badle ja sakte hain. Free Gemini models ke naam kabhi badal sakte hain; agar "model setting theek nahi" ka error aaye to naye naam wahan likh dein.
- Data ek JSON file mein hai, jo kuch sau users tak theek chalta hai. Us se zyada ke liye asli database lagana hoga.
